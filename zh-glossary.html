电网侧储能术语表

用1〜3句话定义了查看、出售、购买项目时会遇到的词语。制度方面的词语依据以公开资料为基础的本公司解说文章撰写，买卖方面的词语依据本公司实务中的用法撰写。详细内容请见各词条末尾的文章。

基础词语辅助服务市场・收益电力系统・接续研讨制度・监管・税务买卖・项目实务

基础词语

电网侧储能（系統用蓄電池）
直接接入电力系统、为支撑系统的供需与频率而设置的储能电池设备。与自用型储能电池不同，一般输配电事业者支付报酬的对象是“储存电力并随时处于可响应状态的待命”本身，收益由辅助服务市场、容量市场、批发电力市场这3个市场决定。根据电气事业法，无论出力大小，均属事业用电气工作物（储能电站）。 什么是电网侧储能（支柱页面）→
高压・特高压・低压（電圧区分）
并网时按受电电力划分的类别。不足50kW为低压，50kW以上、不足2,000kW为高压，2,000kW以上为特高压，类别不同，受电设备、手续和保安的要求轻重也不同。高压项目多按1,990kW前后设计，是因为超过2,000kW这条线就要按特高压的设备和手续办理。 “低压就简单”并不成立 →
出力（MW）与容量（MWh）
出力（kW、MW）是一次能够输入、输出的电力大小，容量（kWh、MWh）是能够储存的电量。项目以出力和容量的组合来表示，容量除以出力得到的时间就是“持续时间”。容量越大，储能电池的数量越多，占建设费用的大部分。 电网侧储能的建设费用 →
持续时间（継続時間）
以额定出力持续放电的时间，即容量（MWh）÷出力（MW）。辅助服务市场的各商品所要求的持续时间不同（一次调整力为5分钟以上等），时间越长，可投标的商品越多，但储能电池数量增加，建设费用上升。 辅助服务市场的5种商品 →
响应（応動・応動時間）
针对一般输配电事业者的指令或频率变化，储能电池开始改变出力、直至达到所要求出力的速度。辅助服务市场为各商品规定了响应时间，一次调整力要求在10秒以内。储能电池比火电响应更快，这一差距体现为中标单价的差距。无法响应则会被扣减，并被挤出市场。 什么是一次调整力 →
调整力（調整力）
为填补需求与供给的偏差以及频率的紊乱，一般输配电事业者预先确保的“可上调、下调出力的能力”。在辅助服务市场中作为一次至三次的商品被采购，由储能电池、发电机和需求侧设备提供。 日本辅助服务市场（指南）→
一般输配电事业者（一般送配電事業者）
拥有输电线和配电线，对所在区域的供需与频率负责的事业者（各区域电力公司的输配电部门）。它是接续研讨回复书、工程费负担金、并网承诺的对方，在辅助服务市场中也是调整力的买方。 接续研讨・合同申请的新规则 →
电网规范（グリッドコード・系統連系技術要件）
将发电设备或储能电池接入电力系统时应满足的技术要求的总称。由资源能源厅的指南，以及各一般输配电事业者的并网技术要求和并网规程构成，修订由OCCTO的电网规范研讨会讨论。2027年4月的修订预计将以使用已取得JC-STAR★1的产品为前提。 JC-STAR★1何时强制 →
设备更换（機器の置き換え・交換）
在运营中的储能电站，对劣化的储能电池或PCS、EMS等设备进行置换、更换。若要换成与接续研讨回复书中的设备不同的设备，需办理设备变更手续（需确认是否必要）；2027年4月以后的设备更新适用按设备单位的JC-STAR★1符合性要求，用补贴购置的设备若在处分限制期间内更换，则涉及SII的事先批准。 更换设备时应确认什么 →

辅助服务市场・收益

辅助服务市场（需給調整市場）
一般输配电事业者向卖方购买“调整力”的市场，调整力用于填补需求与供给之间的偏差。卖方是持有储能电池或发电机的经营者，在指定时段以指定出力随时可以运行的待命状态，本身即可获得报酬。由EPRX运营。 日本辅助服务市场（指南）→
EPRX（电力供需调整力交易所）
运营辅助服务市场的一般社团法人。正式名称为电力供需调整力交易所。它与批发电力市场JEPX是相互独立的另一个法人、另一个市场，并公布交易实绩。 EPRX是什么 →
一次调整力
辅助服务市场五项商品中最先吸收频率瞬时波动的商品。要求在10秒内响应、持续5分钟以上，储能电池拿下了中标量的9成以上。 一次调整力与五项商品 →
复合商品
在辅助服务市场中，将一次至三次调整力①的商品合并起来一并报价的方式。 五项商品 →
ΔkW
辅助服务市场中交易的“预留容量”的单位。除实际输出的电量之外，预留容量这一承诺本身也会获得付款。 另一层天花板 →
上限价格（辅助服务市场）
ΔkW报价所设的上限。一次调整力、二次调整力①和复合商品原为15日元/ΔkW·30分钟，自2026年9月1日的实际供需起降至10日元。 上限价格下调后消失的金额 →
一定额（指南中的）
《辅助服务市场指南》规定的报价上限的另一层天花板。其思路是按“损失的利润＋一定额＋交易手续费”设定报价上限，它触及不到其他电源，只触及储能电池。 另一层天花板 →
日前交易化（前日取引化）
辅助服务市场的一次至三次调整力①，从一次性对一周的量集中报价的“周度商品”，改为前一日14时对次日报价的“日前交易”的制度变更（自2026年3月13日的交易起）。
周度商品（週間商品）
在实际供需前约一周，对一周的调整力一并报价、中标的方式。2026年3月改为日前交易后被废止。
募集量的1σ化
将一次调整力和二次调整力①的募集量，从覆盖99.9%波动的“3σ”改为覆盖84%的“1σ”。在市场上采购的调整力总量大幅减少。 募集量与1σ化 →
容量市场（主拍卖）
由电力广域运营推进机构（OCCTO）运营、预先确保未来供给能力（kW）的市场。以单年为单位，对4年后的实际供需年度的量进行中标。
长期脱碳电源拍卖（LDA）
2023年度作为容量市场的一部分创设的制度。将20年的固定容量收入，与返还其他市场约9成收益的机制组合在一起。中标项目在中途没有可出售的交易路径。 LDA是什么 →
全市场型（full merchant）
不依赖LDA等固定收入合同，仅靠JEPX、辅助服务市场、容量市场的市场收入使储能事业成立的运营方针。 什么是全市场型（full merchant）→
市场价格风险（merchant risk）
在没有固定价格长期合同、于市场上卖出的部分直接成为收入的形态（merchant）下，自己承担市场价格波动。 什么是merchant →
容量租赁合同（トーリング契約／承购合同）
将储能电站的容量与运营权以固定费用交给对方（承购方），由该对方承担市场价格波动风险的合同。在日本，它与“承购合同（offtake）”几乎同义使用，与火电的Tolling（委托加工）属于同一类型。 什么是容量租赁合同 →
收益堆叠
用同一块储能电池，叠加获取批发电力市场（JEPX）、辅助服务市场、容量市场这多个收益来源。 三大收益来源与堆叠 →
聚合商
编排储能电站的充放电并向市场报价的经营者。随收费方式（毛额或净额）不同，即使费率相同，实得金额也不同。 聚合商费用的毛额与净额 →
JEPX（日本批发电力交易所）
买卖电力本身（kWh）的批发电力市场。与辅助服务市场（EPRX）是另一个法人、另一个市场。 三大收益来源 →

电力系统・接续研讨

接续研讨（接続検討）
一般输配电事业者研讨能否接入电力系统的手续。回复书中记载并网条件（接入点、工程费负担金、工期）。
接续研讨回复书（接続検討回答書）
输配电事业者出具的、记载电力系统并网条件的回复书。它是开发权的核心文件，负担金和工期都是纸面上的研讨，并非确定承诺。自回复起1年后失效。
注意事项说明书
附在接续研讨回复书上的广域机关通用格式。它表明负担金和工期都是纸面上的研讨，会随合同申请之后的现场调查和用地谈判而变动。
接续研讨必要性确认（接続検討の要否確認）
在收到接续研讨回复后变更储能电池或PCS等设备时，向一般输配电事业者确认是否需要重新进行接续研讨的手续。使用OCCTO的格式申请，回复原则上为1个月，不收研讨费。 接续研讨回复后的设备变更 →
合同申请（正式回复）
接续研讨的下一阶段。对合同申请的正式回复确定工程费负担金，项目的阶段升一级。
工程费负担金
并网工程费中由申请人承担的金额。接入点是输电线还是配电线，金额的数量级会不同；在正式回复时确定，并网工期以从缴款起算的情形为主。 并网工程费为何相差10倍 →
并网承诺（接续合同）
基于对合同申请的正式回复，获得并网的承诺。有已确定的事项，也有仍会变动的事项。
空占对策（2026年4月的新规则）
针对接续研讨件数激增采取的措施。自2026年4月起，开始提高保证金、要求必须提交土地权属等，已开发完成的项目与即将着手的项目之间的差距拉大。 接续研讨、合同申请的新规则 →
接续研讨数量上限
自2026年8月1日起，对电网侧储能电池的接续研讨，设定的每个事业者的件数（收到回复之前的）上限。
非确定性并网（non-firm）
以电力系统拥堵时将被无补偿地限制出力为前提，允许新的并网的制度。 非确定性并网与弃电风险 →
并网预期（連系の見込み）
本公司项目一览中的表示方式。已确定运营开始预定的项目以年月表示，尚未确定的项目以回复书中记载的距并网的月数表示。

制度・监管・税务

JC-STAR
评估IoT设备应具备的安全功能，并以星数（★1〜★4）表示符合情况的标签制度。由IPA运营，在经济产业省的监督下运作。
JC-STAR★1强制化
并网时必须使用已取得JC-STAR★1的产品（PCS、EMS等）。特高压、高压为2027年4月，低压50kW以下为2027年10月，基准是接续合同申请而不是并网日。 JC-STAR★1何时强制 →
PCS／EMS
转换储能电池的直流与电力系统交流的装置（PCS），以及控制充放电的管理系统（EMS）。它们是JC-STAR的对象设备；储能电池电芯本体不直接与网络通信，因此不在对象之内。
大胆投资促进税制（特定生产率提升设备等投资促进税制）
对获得经济产业大臣确认的设备投资，允许即时折旧或税额抵免的税制。确认申请的受理于2026年7月31日开始。 即时全额折旧，申请受理已经开始 →
即时全额折旧（即時償却）
将设备取得额的全额，在包含开始用于业务之日的事业年度内计提折旧。它是税款的递延，与税额抵免（税款的纯粹减少）性质不同。 即时全额折旧 →
储能电站（电气事业法）
在电气设备技术标准省令的定义中，指将从场外输送来的电力储存在场内的电力储存装置中，并以相同电压、频率向场外输送的场所。无论出力大小，均属事业用电气工作物，需要保安规程和电气主任技术者。 “低压就简单”并不成立 →
电气主任技术者
负责监督事业用电气工作物的施工、维护、运行保安的有资质人员。储能电站无论出力大小都必须选任。 电网级储能运维 →
市街化调整区域
依据城市规划法，开发和建筑均需许可的区域。目前尚未发现公布了准许储能电站的审查标准的地方政府，位于该区域的项目很难获得许可。若为农地，另需农地转用许可。
外汇法（对内直接投资）
海外资本收购日本储能电站时适用的、对内直接投资的申报与审查监管。 外国资本需跨越的关口 →
补助金的处分限制
以补助金取得的财产，在处分限制期间内进行出售、交换、出借、废弃或提供担保，需要事先获得SII的承认。退出价格上会持续被打折扣。 电网级储能的补贴 →

买卖・项目实务

开发权
没有法律上的定义，是将接续研讨回复书与项目用地的使用权等合在一起作为一个整体来称呼的实务用语。 开发权的转让 →
权利转让
在接续研讨回复和用地落定的阶段，连同权利一起取得的买法。工程可由买方直接与自己选定的EPC签约，可以避免在建成之前向卖方预付大笔款项的形式。
完工交付（完成渡し）
以建成状态接收的买法。省心，但通例是在完工前支付大部分价款，因此要考察卖方的信用。 买法有四种 →
运营中项目（稼働中案件）
已通电并参与市场的储能电站。因为能看到销售收入实绩，价格更高，且参与市场的资格不会自动转移给买方。
名义变更
向输配电事业者提出的、将接续研讨的申请人名义从卖方变更为买方的申请。审查期间因电力公司和项目而异，通例是将付款分为申请时和完成时两次。 转让的手续 →
匿名简介（匿名ティーザー）
不公开地号、卖方和价格，仅展示所在县、规模、并网预期、进展以及取得形式的项目概要。可在签订保密协议之前查看。
DealRoom
在签订保密协议之后，可以一并查看接续研讨回复书、登记簿、工程费负担金凭证等DD资料的本公司平台。
尽职调查（DD）
在购买之前，核查文件内容是否越过了会改变判断的界线的工作。涉及回复书、合同、权利的名义与承继、用地、区域、设备等9个领域。 购买前的技术核查 →
EPC
承包设计、采购、建设的建设公司。本公司不承包建设，也与特定的制造商、EPC没有资本关系。 储能电站开发的全流程 →
O&M
运行与维护。在聚合商的充放电、主任技术者的法定检查、制造商的维修之间，仍留有无人负责的领域。 电网级储能运维 →
期望损失（EAL）
以“概率×损失金额”衡量灾害风险的指标。不是去等一块完全没有浸水风险的土地，而是用金额来决定在多高的频率以内把损失降为零。 用期望损失衡量灾害风险 →
SPC（特别目的公司）
为持有项目而设立的公司。在连同容器一并购买的买法中，容器里的内容也要一并承接。 容器的选择 →
取得形式（取得の形）
本公司项目一览中的分类：权利转让（开发中）、完工交付、运营中这三种。
