系統用蓄電池の用語集

案件を見る・売る・買うときに出てくる言葉を、1〜3文で定義しました。制度の言葉は公表資料にもとづく当社の解説記事から、売買の言葉は当社の実務の使い方から書いています。くわしくは各語の末尾の記事へ。

需給調整市場・収益

需給調整市場じゅきゅうちょうせいしじょう
需要と供給のずれを埋める「調整力」を、一般送配電事業者が売り手から買う市場。売り手は蓄電池や発電機を持つ事業者で、指定の時間帯に指定の出力でいつでも動ける状態で待つことに対して報酬を受け取る。運営は EPRX。 需給調整市場とは（ガイド） →
EPRX（電力需給調整力取引所）イーピーアールエックス
需給調整市場を運営する一般社団法人。正式名称は電力需給調整力取引所。卸電力の JEPX とは独立した別の法人・別の市場で、取引実績を公表している。 EPRXとは →
一次調整力いちじちょうせいりょく
需給調整市場の5商品のうち、周波数の瞬時の変動を最初に吸収する商品。応動は10秒以内、継続は5分以上を求められ、蓄電池が約定の9割超を取る。 一次調整力とは →
複合商品ふくごうしょうひん
需給調整市場で、一次〜三次①の商品をまとめて入札する方式。 需給調整市場の5商品 →
ΔkW（デルタキロワット）
需給調整市場で取引される「空けておく容量」の単位。実際に電気を出した分とは別に、空けておく約束そのものにお金が払われる。 もう一枚の天井 →
上限価格（需給調整市場）じょうげんかかく
ΔkW の札に付けられる上限。一次調整力・二次調整力①・複合商品は15円/ΔkW・30分から、2026年9月1日実需給分で10円に下がった。 上限価格の引き下げで消える金額 →
一定額（ガイドラインの）いっていがく
需給調整市場ガイドラインが定める、札の上限のもう一枚の天井。逸失利益＋一定額＋売買手数料で札の上限を置く考え方で、ほかの電源には届かず蓄電池にだけ届く。 もう一枚の天井（COLUMN 50） →
前日取引化ぜんじつとりひきか
需給調整市場の一次〜三次①が、1週間分をまとめて入札する「週間商品」から、前日14時に翌日分を入札する「前日取引」に移った制度変更（2026年3月13日の取引分から）。 前日取引化とは →
週間商品しゅうかんしょうひん
実需給の1週間ほど前に、1週間分の調整力をまとめて入札・約定していた方式。2026年3月の前日取引化で廃止された。 週間商品とは何だったか →
募集量の1σ化いちシグマか
一次調整力と二次調整力①の募集量を、ぶれの99.9%を覆う「3σ」から84%を覆う「1σ」に変えたこと。市場で調達する調整力の総量が大幅に減った。 募集量と1σ化 →
容量市場（メインオークション）ようりょうしじょう
電力広域的運営推進機関（OCCTO）が運営する、将来の供給力（kW）をあらかじめ確保する市場。4年先の実需給年度分を単年で約定する。 容量市場メインオークションと蓄電池 →
長期脱炭素電源オークション（LDA）ちょうきだつたんそでんげんオークション
容量市場の一部として2023年度に創設された制度。20年の固定容量収入と、他市場の収益の約9割を還付する仕組みを組み合わせる。落札案件は途中で売る商流が無い。 LDAとは →
フルマーチャント
LDA などの固定収入契約に頼らず、JEPX・需給調整市場・容量市場の市場収入だけで蓄電池事業を成立させる運用方針。 フルマーチャントとは →
マーチャントリスク
固定価格の長期契約を持たず、市場で売った分がそのまま収入になる形（マーチャント）で、市場価格の変動を自分で負うこと。 マーチャントとは →
トーリング契約（オフテイク契約）トーリングけいやく
蓄電所の容量と運用権を固定料金で相手（オフテイカー）に渡し、市場価格の変動リスクをその相手が引き受ける契約。国内では「オフテイク契約」とほぼ同じ意味で使われ、火力のトーリング（委託加工）と同型。 トーリング契約とは →
収益のスタッキング
卸電力市場（JEPX）・需給調整市場・容量市場という複数の収益源を、同じ蓄電池で重ねて得ること。 3つの収益源とスタッキング →
アグリゲーター
蓄電所の充放電を組んで市場に入札する事業者。手数料の取り方（グロスかネットか）で、同じ料率でも手取りが変わる。 アグリゲーター手数料のグロスとネット →
JEPX（日本卸電力取引所）ジェイイーピーエックス
電気そのもの（kWh）を売買する卸電力市場。需給調整市場（EPRX）とは別の法人・別の市場。 3つの収益源 →

系統・接続検討

接続検討せつぞくけんとう
系統につなげるかどうかを、一般送配電事業者が検討する手続き。回答書に連系の条件（接続点・工事費負担金・工期）が書かれる。 接続検討回答書を毎日読む当社が、最初に見る6か所 →
接続検討回答書せつぞくけんとうかいとうしょ
送配電事業者が発行する、系統連系の条件を記載した回答書。開発権の核になる書類で、負担金も工期も机上の検討であり確約ではない。回答から1年で失効する。 回答書の読み方 →
注意事項説明書ちゅういじこうせつめいしょ
接続検討回答書に付く広域機関の共通様式。負担金も工期も机上の検討で、契約申込みのあとの現地調査や用地交渉で動くことを示す。 回答書の6か所を、当社はこう読む →
接続検討の要否確認せつぞくけんとうのようひかくにん
接続検討の回答を受けた後に蓄電池や PCS などの設備を変える場合、あらためて接続検討が必要かどうかを一般送配電事業者に確かめる手続き。OCCTO の様式で申し込み、回答は原則1か月、検討料はかからない。 接続検討の要否確認とは →
契約申込み（本回答）けいやくもうしこみ
接続検討の次の段階。契約申込みへの本回答で工事費負担金が確定し、案件の段階がひとつ上がる。 連系承諾で確定するもの、まだ動くもの →
工事費負担金こうじひふたんきん
系統連系のための工事費のうち、申込者が負担する額。接続点が送電線か配電線かで桁が変わり、本回答で確定し、入金から連系の工期を数えるものが中心。 系統連系工事費が10倍違う理由 →
連系承諾（接続契約）れんけいしょうだく
契約申込みへの本回答に基づいて連系を承諾されること。確定するものと、なお動くものがある。 連系承諾で確定するもの →
空押さえ対策（2026年4月の新ルール）からおさえたいさく
接続検討の件数が急増したことへの措置。2026年4月から保証金の増額と土地権原の提出義務化などが始まり、開発済みの案件とこれから着手する案件の差が広がった。 接続検討・契約申込みの新ルール →
接続検討数の上限
2026年8月1日から、系統用蓄電池の接続検討について、一事業者あたりの件数（回答を受ける前のもの）に付いた上限。 数字で見る回答書 →
ノンファーム型接続ノンファームがたせつぞく
系統混雑時に無補償で出力制御されることを前提に、新規の系統接続を認める制度。 ノンファーム型接続と出力制御リスク →
連系の見込みれんけいのみこみ
当社の案件一覧での表し方。運転開始の予定が決まっている案件は年月で、決まっていない案件は回答書に書かれた連系までの月数で示す。 売り案件の市場データ →

制度・規制・税

JC-STARジェイシースター
IoT 機器が備えるべきセキュリティ機能を評価し、適合状況を★の数（★1〜★4）で表すラベリング制度。IPA が運営し、経済産業省の監督下で運用される。 JC-STARとは ── ★1〜★4の違いと対象製品 →
JC-STAR★1 の義務化
系統連系で JC-STAR★1 取得製品（PCS・EMS 等）が必須になること。特別高圧・高圧は2027年4月、低圧50kW未満は2027年10月で、基準は連系日でなく接続契約申込み。 JC-STAR★1の義務化はいつから →
PCS／EMSパワーコンディショナー／エネルギーマネジメントシステム
蓄電池の直流と系統の交流を変換する装置（PCS）と、充放電を制御する管理システム（EMS）。JC-STAR の対象機器で、蓄電池セル本体はネットと直接通信しないため対象外。 対象機器 →
大胆な投資促進税制（特定生産性向上設備等投資促進税制）だいたんなとうしそくしんぜいせい
経済産業大臣の確認を受けた設備投資に、即時償却または税額控除を認める税制。確認申請の受付は2026年7月31日に始まった。 即時償却、受付が始まった →
即時償却そくじしょうきゃく
設備の取得額の全額を、事業に使い始めた日を含む事業年度に償却すること。税金の先送りであり、税額控除（税金の純粋な減額）とは性質が違う。 即時償却・一括償却 →
蓄電所（電気事業法）ちくでんしょ
電技省令の定義で、構外から伝送される電力を構内の電力貯蔵装置で貯蔵し、同じ電圧・周波数で構外へ伝送する所。出力にかかわらず事業用電気工作物で、保安規程と電気主任技術者が要る。 「低圧なら簡単」は通用しない →
電気主任技術者でんきしゅにんぎじゅつしゃ
事業用電気工作物の工事・維持・運用の保安を監督する有資格者。蓄電所は出力にかかわらず選任が要る。 系統用蓄電所のO&M →
市街化調整区域しがいかちょうせいくいき
都市計画法で開発も建築も許可制になる区域。蓄電所を許可する審査基準を公表している自治体はまだ見当たらず、該当する案件は許可が出にくい。農地なら別に農地転用の許可が要る。 市街化調整区域の土地は蓄電池用地になるか →
外為法（対内直接投資）がいためほう
海外資本が日本の蓄電所を取得するときにかかる、対内直接投資の届出・審査の規制。 外国資本が越える関門 →
補助金の処分制限ほじょきんのしょぶんせいげん
補助金で取得した財産は、処分制限期間内の売却・交換・貸付・廃棄・担保供与に SII の事前承認が要ること。出口の価格に割引が乗り続ける。 系統用蓄電池の補助金 →

売買・案件の実務

開発権かいはつけん
法律上の定義は無く、接続検討回答書と事業用地の利用権などを一つのパッケージとして呼ぶ実務の言葉。 開発権の譲渡 →
権利譲渡けんりじょうと
接続検討の回答と用地が固まった段階で、権利ごと取得する買い方。工事は買い手が選んだ EPC と直接契約でき、建つ前に売主へ大金を預ける形を避けられる。 案件を買う →
完成渡しかんせいわたし
建った状態で受け取る買い方。手離れは良い一方、完成前に代金の大半を払うのが通例で、売主の与信が問われる。 買い方は4つある →
稼働中案件かどうちゅうあんけん
通電して市場に参加している蓄電所。売上の実績が見えるぶん高くなり、市場参加の資格は自動では買い手に移らない。 案件を売りたい方へ →
名義変更めいぎへんこう
接続検討の申込者名義を売主から買主に変える、送配電事業者への申請。審査の期間は電力会社と案件で変わり、申請の時点と完了の時点で支払いを分けるのが通例。 譲渡の手続き →
匿名ティーザーとくめいティーザー
所在県・規模・連系の見込み・進み具合・取得の形までを、地番・売主・価格を伏せて示す案件の概要。秘密保持契約の前に見られる。 販売中の案件一覧 →
DealRoomディールルーム
秘密保持契約の後に、接続検討回答書・登記・工事費負担金の証憑などの DD 資料を一括で見る当社の場。 案件一覧から契約までの順番 →
デューデリジェンス（DD）
買う前に、書類の中身が判定を変える線を越えているかを確かめる作業。回答書・契約・権利の名義と承継・用地・区域・設備の9領域を見る。 買う前の技術チェック →
EPCイーピーシー
設計・調達・建設を請け負う建設会社。当社は建設を請け負わず、特定のメーカー・EPC と資本関係を持たない。 蓄電所開発の全工程 →
O&Mオーアンドエム
運転と保守。アグリゲーターの充放電、主任技術者の法定点検、メーカーの修理の間に、誰もやらない領域が残る。 系統用蓄電所のO&M →
期待損失（EAL）きたいそんしつ
災害リスクを「確率×被害額」で測る指標。浸水の恐れが一切ない土地を待つのではなく、どの頻度まで損害をゼロにするかを金で決める。 災害リスクは期待損失で測る →
SPC（特別目的会社）エスピーシー
案件を持たせるために作る会社。器ごと買う買い方では、器の中身も引き受ける。 器の選択 →
取得の形しゅとくのかたち
当社の案件一覧での区分。権利譲渡（開発中）・完成渡し・稼働中の案件の3つ。 売り案件の市場データ →
