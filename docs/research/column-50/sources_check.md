> ⚫ 固定費回収の上限額は、当年度分の減価償却費等を含む固定費から他市場で得られる収益を差し引いた額とする。

- R3 は α を上限の100%で仮置きしている。OCCTO「2029年度向け 容量市場メインオークション用調整係数」（2025年7月31日）では、純揚水・東京エリア・4時間の係数は月別に 55.9〜79.7%（12か月の単純平均 70.8%）。蓄電池は揚水と同じ調整係数を使う整理（エネ庁 2023/6/21 資料7 PDF p.6 の注）。
- 年間一律の係数は様式2で月別の入力から自動計算される（様式2補足説明 p.8）。その計算方法は今回確かめていない。
- 仮に α を月別の最小・平均・最大で置くと、R3 の2年目（東京・応札可能率90%）は 1.091円・0.949円・0.863円になる（R3 の他の入力はそのまま）。未確認の推定で、本文に使うなら年間一律の係数を確かめてから。

## 使ったコマンド（主なもの）

- 到達: `curl -sS -A "<上記UA>" -H "Accept-Language: ja,en;q=0.8" -L -o <保存先> -w "%{http_code}\t%{url_effective}\t%{content_type}\t%{size_download}" <URL>`
- WAF の確認: `curl … -D -` で `HTTP/2 202`・`x-amzn-waf-action: challenge` を確認し、間隔を空けて取り直した。
- PDF: `pdftotext -layout -f N -l N <PDF> -`。2段組みで行が混ざる頁は `pdftotext`（-layout なし）で文のつながりを確かめた。図の数字は `pdftoppm -f N -l N -r 80 -png` で描いて目で確かめた（第14回資料3 p.46、経産省資料6 p.5、エネ庁 2025/6/23 資料3 p.9）。
- 法令: e-Gov 法令API（`/api/1/articles;lawId=325AC0000000226;article=350`、`/api/1/lawdata/340M50000040015`）。
- EPRX の CSV: CP932 で読み、キー `20260901B01` の行を抜き出して R4 の表と照合した。
- 引用の文字列は、取得した全資料のテキスト（空白を除き NFKC で正規化）に含まれるかを機械で照合し、外れたものは 2段組みの混ざりと分かるまで原文で確かめた。
