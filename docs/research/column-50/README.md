## 試算の式と入力（50-3）

- 一定額 ＝（当年度分の固定費 − 他市場収益）÷ 想定応札量。ガイドライン p.6 は、上限額の定義と「上限額を想定応札量で除した額」を2つの箇条で書いていて、一文の形は第21回制度設計・監視専門会合 資料6 p.4 の注にある。当年度分の固定費を回収した後と、上限額がマイナスの年、B種の計算値が0.33円を下回る年は A種の0.33円（需給調整市場ガイドライン 2026年3月13日改定 p.6〜7。マイナスと0.33円未満の扱いは当社の読み）。
- 入力は `scripts/column50/inputs.json` だけ。調整係数は `occto_coefficients.md` の月別値から12か月平均を計算する（様式2の期待容量＝各月の係数×各月の放電可能電力の12か月平均。放電可能電力は2,000kWで毎月同じと置き、期待容量は kW の整数に四捨五入）。
- 公表単価の無い費目（人件費・委託費・保険料・土地賃料・アグリゲーター固定費・蓄電ロス分の託送基本料金）は入れていない。年1,000万円を足すごとに一定額は約0.32円上がる。
- 発電側課金の kW 単価（税込・円/kW・月）は、運開を2027年度と置くので2026年11月1日実施の単価を使う。
  - 東京 100.12（現行 87.01）: 東京電力パワーグリッド「託送供給等約款の変更届出について」（2026年9月11日）の別紙「託送料金単価表」p.4「系統連系受電サービス料金 基本料金 1kW 現行単価87円01銭（税込）改定単価100円12銭（税込）」 https://www.tepco.co.jp/pg/company/press-information/press/2026/pdf/26x4102.pdf 。届出した約款本体（令和8年11月1日実施）の 22(3)イ 基本料金「100円12銭」 https://www.tepco.co.jp/pg/consignment/notification/pdf/takusou_yakkan20260911.pdf とも一致（2026-10-04 確認）。
  - 中部 95.61・関西 116.23・四国 110.04・九州 98.56: 各社の2026年11月1日実施の単価表・ページ（`sources_check.md` の C-15）。
  - 北海道 110.00・東北 93.04・北陸 93.47・中国 85.02: 現行の単価（改定の掲載なし。C-15）。

## 集計の式（50-4）

`scripts/eprx/README.md` に、式・CSV の項目名（原文）・取得日・規約の注意を書いている。要点:

- 落札量加重平均 ＝ Σ(平均落札価格×落札量)÷Σ落札量（電源属地別、落札量0のコマは除く）。価格は精算前の表示値。
- 期間は 2026年4月1日〜8月31日（上限15円）と 9月1日〜29日（上限10円）。速報と確報は混ぜない。
- EPRX の公開データは、商用目的で使うときに EPRX との契約が要る（取引実績ページの注意書き）。大量の自動取得は事前承諾が要るので、CSV は手で1本ずつ取った。
