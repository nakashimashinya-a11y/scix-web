## 試算の式と入力（50-3）

- 一定額 ＝（当年度分の固定費 − 他市場収益）÷ 想定応札量。当年度分の固定費を回収した後と、上限額がマイナスの年、B種の計算値が0.33円を下回る年は A種の0.33円（需給調整市場ガイドライン 2026年3月13日改定 p.6〜7。マイナスと0.33円未満の扱いは当社の読み）。
- 入力は `scripts/column50/inputs.json` だけ。調整係数は `occto_coefficients.md` の月別値から12か月平均を計算する（様式2の期待容量＝各月の係数×各月の放電可能電力の12か月平均。放電可能電力は2,000kWで毎月同じと置き、期待容量は kW の整数に四捨五入）。
- 公表単価の無い費目（人件費・委託費・保険料・土地賃料・アグリゲーター固定費・蓄電ロス分の託送基本料金）は入れていない。年1,000万円を足すごとに一定額は約0.32円上がる。

## 集計の式（50-4）

`scripts/eprx/README.md` に、式・CSV の項目名（原文）・取得日・規約の注意を書いている。要点:

- 落札量加重平均 ＝ Σ(平均落札価格×落札量)÷Σ落札量（電源属地別、落札量0のコマは除く）。価格は精算前の表示値。
- 期間は 2026年4月1日〜8月31日（上限15円）と 9月1日〜29日（上限10円）。速報と確報は混ぜない。
- EPRX の公開データは、商用目的で使うときに EPRX との契約が要る（取引実績ページの注意書き）。大量の自動取得は事前承諾が要るので、CSV は手で1本ずつ取った。
